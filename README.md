## Web 版快速启动

```bash
pip install -r requirements.txt
python web_app.py
```

启动后访问 <http://localhost:8000>，即可通过网页搜索游戏、获取 Steam 清单并生成 SteamTools 可用的 Lua 解锁脚本。
